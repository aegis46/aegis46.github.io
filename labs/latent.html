EXECUTIVE SUMMARY

What happened

Network evidence identified 10.0.2.4 as the attacker host. It performed a broad TCP port scan against 10.0.2.15, then authenticated over SMB and enumerated shares before connecting to the Documents share.

The attacker uploaded shell.aspx to that share. The payload was subsequently requested over HTTP from /Documents/shell.aspx, causing the victim to initiate a reverse connection back to the attacker on TCP port 4443.

Memory analysis identified w3wp.exe, the IIS worker process, as the process associated with the web-shell execution chain. A later child process, updatenow.exe (PID 900), was found executing from the Windows Startup folder.

Static analysis showed that the executable was UPX-packed, had high entropy and imported WSOCK32.dll. The lab ultimately identified the malware family as AgentTesla.

ATTACK CHAIN

From reconnaissance to persistence

01
RECONNAISSANCE

TCP port scan

10.0.2.4 sent SYN packets to a large number of ports on 10.0.2.15, establishing the attacker's service-discovery activity.

02
INITIAL ACCESS

SMB share access

The attacker negotiated SMB2, authenticated as WORKGROUP\root, enumerated shares through IPC$ and connected to \\10.0.2.15\Documents.

03
PAYLOAD DELIVERY

ASPX payload uploaded

An SMB Create/Write sequence showed shell.aspx being written to the Documents share.

04
EXECUTION

Web payload requested

At Sep 10, 2024 01:49:33 EDT, the attacker requested /Documents/shell.aspx over HTTP.

05
COMMAND & CONTROL

Reverse shell

Approximately 18 seconds later, 10.0.2.15 initiated a TCP connection back to 10.0.2.4:4443. Process evidence tied the IIS execution chain to w3wp.exe.

06
PERSISTENCE / MALWARE

Startup-folder executable

w3wp.exe later spawned updatenow.exe. The executable was located in the Windows Startup folder, providing persistence at user logon.

FINAL FINDINGS

Case conclusion

The evidence supports a continuous intrusion chain from TCP service discovery through SMB access and ASPX payload delivery, followed by IIS-hosted reverse-shell execution and deployment of a persistent Windows executable.

Network and memory evidence complemented each other: Wireshark established the attack sequence and timing, while Volatility identified the executable, PID, process hierarchy and persistence path. PEStudio then provided the static characteristics needed to classify the packed malware sample as AgentTesla.
