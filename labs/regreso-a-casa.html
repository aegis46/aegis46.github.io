Regreso a Casa / Confluence compromise

Investigation of an internet-facing Atlassian Confluence compromise that progressed into malicious SSH access, replacement of the system SSH client, credential harvesting through a malicious shared library, XOR-obfuscated C2 infrastructure and nation-state attribution.

EXECUTIVE SUMMARY

What happened

The investigation began with a public-facing Atlassian Confluence Server. Application and audit logs showed abnormal setup activity consistent with exploitation of CVE-2023-22515, a critical broken-access-control vulnerability that could be used to create unauthorised administrator access.

After initial compromise, the threat actor established interactive SSH access using the dev1 account. The investigation then shifted from application logs to host forensics to determine how credentials were being stolen when the development server authenticated to other systems.

Package verification and filesystem metadata showed that /usr/bin/ssh had been replaced or modified. A suspicious shared object, /usr/lib/libssh.so, appeared in the same compromise window and was identified as the credential-harvesting component.

Reverse engineering recovered XOR-obfuscated C2 configuration and functions responsible for transmitting credentials. One recovered C2 address overlapped with infrastructure publicly documented in a Chinese APT campaign targeting Cambodian government organisations.

MALWARE ANALYSIS

Credential-harvesting shared library

The suspicious library /usr/lib/libssh.so was a 64-bit ELF shared object. Its timestamps placed it directly inside the host-compromise window.

The MD5 hash was:

6d350cb8f42b9bfcbd8e0a4ca1b3e847
OBFUSCATIONxor_decrypt()TRANSMISSIONsend_credential()NETWORK LIBRARYlibcurl
REVERSE ENGINEERING

Threaded credential sender

The send_credential_thread function begins by creating a stack frame and reserving 0x850 bytes:

push rbp
mov  rbp,rsp
sub  rsp,0x850

0x850 is 2128 bytes. The function later formats request data, applies libcurl options and calls curl_easy_perform. The higher-level send_credential function creates the new thread and is the function identified by the lab as responsible for sending stolen credentials to C2.

C2 CONFIGURATION

XOR-obfuscated infrastructure

The library contained an array of encrypted URLs. init_urls iterated through the entries, allocated memory for each target, and passed the data to xor_decrypt. The decoded values were stored in target_urls and later consumed by the sender thread.

encrypted_urls[]
      ↓
init_urls()
      ↓
xor_decrypt()
      ↓
target_urls[]
      ↓
send_credential_thread()

Recovered infrastructure included 104.248.153.204.

THREAT INTELLIGENCE

Infrastructure overlap and attribution

Palo Alto Networks Unit 42 documented 104.248.153.204 as part of target-facing command-and-control infrastructure used in a campaign affecting at least 24 Cambodian government organisations.

That reporting identified targets across national defence, election oversight, finance, commerce, telecommunications and other government functions.

Unit 42 assessed with high confidence that the activity was associated with Chinese APT actors. The infrastructure, targeting pattern and actor working hours were consistent with a China-linked cyberespionage operation.

For the lab, the victim country was therefore Cambodia, and the likely nation state was China.

FINAL FINDINGS

Case conclusion

The evidence supports a continuous intrusion chain from exploitation of an internet-facing Confluence service through malicious SSH access and host-level credential theft. The threat actor altered the local SSH tooling, deployed a malicious shared library, captured authentication material and transmitted it to attacker-controlled infrastructure.

The recovered C2 data connected the host artefacts to publicly reported Chinese APT infrastructure used against Cambodian government organisations. The case required correlation across application logs, Linux authentication records, package integrity, ext4 metadata, ELF reverse engineering and external threat intelligence.
